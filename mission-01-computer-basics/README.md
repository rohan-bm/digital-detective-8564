# Mission 1 — Know your computer

## 1. Task / objective
Explain how a computer receives input, processes data, produces output, and stores results using the IPOS model. Identify everyday hardware components, classify software into operating system, application, and utility types, and describe three computer-based systems used in daily life.

## 2. Work completed

### Task 1.1 — Trace one activity using IPOS
**Chosen activity:** Typing and saving a study note in a text editor on my laptop.

| Stage | What happens in your example? | Possible hardware / component |
| :--- | :--- | :--- |
| **Input** | I press keys on the keyboard to type sentences and click the Save button using the trackpad. | Keyboard, trackpad / mouse |
| **Processing** | The processor receives the keystroke signals, the operating system routes them to the text editor, and the editor holds and updates the document in memory. | CPU / processor, RAM (memory) |
| **Output** | Each typed character and the updated file status appear immediately on the display so I can read and verify what I wrote. | Laptop screen / monitor, graphics hardware |
| **Storage** | When I save the file, the data in RAM is written permanently as a `.md` or `.txt` file so it stays available after turning off the computer. | Solid-State Drive (SSD) |

**How the activity moves from input to output and storage:**
First, physical key presses are converted into electrical signals and passed as **input** to the computer. Next, during **processing**, the CPU and memory interpret those signals as characters and update the document in RAM. Almost immediately, the computer sends visual **output** to the screen so I see the text as I type. Finally, when I choose Save, the **storage** stage writes the document from temporary memory (RAM) onto the non-volatile SSD so it is preserved for future use.

## 4. My understanding
Every computing task follows the **IPOS cycle** (Input, Processing, Output, Storage). Input devices bring raw actions or data into the system, the CPU and RAM process them, output devices present the result to the user, and storage keeps important data safe even when power is turned off.

Understanding the difference between **hardware** (physical parts you can touch) and **software** (instructions that tell the hardware what to do) also clarifies how software layers work together: **operating system software** coordinates the machine itself, **application software** helps the user complete specific tasks, and **utility software** helps inspect, maintain, and manage the computer. Embedded and everyday computer systems like ATMs and ticket machines follow the same IPOS principles even though they do not look like laptops.
