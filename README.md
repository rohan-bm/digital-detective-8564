## About This Project

This repository contains my complete mini system report and practical lab work for **The Digital Detective** assignment. The goal of the assignment is to explore how a computer works from physical components and operating system internals up to command-line tools, Python execution, data representation, version control, and computer networking.

> **Workflow Note:** Each mission (Missions 0 through 8) was completed in sequence, documented in its own `README.md` using a consistent structure, and committed and pushed separately.

## Topics Explored

- **Computer Fundamentals & IPOS:** Input, Processing, Output, and Storage cycle; hardware vs. software categories; everyday embedded computer systems.
- **Terminal & File Management:** Navigating directories, creating/copying/renaming/appending files safely, using command flags and pipes (`|`), and inspecting Homebrew.
- **Operating Systems:** OS environment checks, disk usage, running processes and PIDs, absolute vs. relative paths, file permissions (`r`, `w`, `x`), and core OS responsibilities.
- **Program Execution:** Running a Python script from Terminal and comparing compilers vs. interpreters.
- **Number Systems & Text Encoding:** Manual decimal/binary/hexadecimal conversions, Python verification, building a CLI number converter, and ASCII/UTF-8 character encoding.
- **Git & GitHub Collaboration:** Staging vs. committing, commit history inspection, branching (`update-about`), and opening a Pull Request.
- **Computer Networks:** LAN/MAN/WAN, DNS, routers, protocols, packet switching, client-server communication, connectivity checks, and how a website loads.

## How to Run the Number Converter

To run the Python number converter built in Mission 5 from its mission folder:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

Enter a whole decimal number when prompted (for example `13`, `25`, or `255`), and the program outputs both the binary and hexadecimal equivalents.
